# SUMMIT School ERP: วิธีติดตั้งบนคอม โทรศัพท์ และไอแพด

โฟลเดอร์นี้คือตัวโปรแกรมทั้งหมด เมื่อนำขึ้นเว็บแล้ว จะติดตั้งเป็นแอปได้ทุกเครื่อง มีไอคอนบนหน้าจอเหมือนแอปทั่วไป และเปิดใช้ได้แม้ไม่มีอินเทอร์เน็ต หลังจากเปิดครั้งแรกแล้ว

## เรื่องที่ต้องรู้ก่อน
- **ข้อมูลอยู่แยกกันในแต่ละเครื่อง:** ข้อมูลในคอม โทรศัพท์ และไอแพดยังไม่รวมกันจนกว่าจะทำ "ฐานข้อมูลกลาง" (ต้องทำในแชทที่เปิดอินเทอร์เน็ต) ระหว่างนี้ให้ใช้ **เครื่องหลักเครื่องเดียว** ในการบันทึกข้อมูล
- **ย้ายข้อมูลระหว่างเครื่อง:** เครื่องเดิมกด “คัดลอกข้อมูลสำรอง” ที่ ตั้งค่า › สำรอง/กู้คืนข้อมูล แล้วเครื่องใหม่วางข้อความในช่อง “กู้คืนจากข้อความ”
- **รูปสลิปไม่ย้ายตาม:** รูปสลิปเก็บอยู่ในเครื่องที่แนบเท่านั้น สลิปตัวจริงยังอยู่ในแอปธนาคารและใน LINE

## ขั้นที่ 1: นำโปรแกรมขึ้นเว็บ (ฟรี ทำครั้งเดียว)

### ทางเลือก ก: GitHub Pages (แนะนำ)
1. เข้า github.com แล้วล็อกอินบัญชีของคุณ
2. กด **New repository** ตั้งชื่อ `summit-erp-app` เลือก **Public** แล้วกด Create
   - ถ้าเลือก Public คนอื่นจะเห็นได้แค่ตัวโค้ดโปรแกรม ข้อมูลนักเรียนไม่ได้อยู่ในนี้ เพราะเก็บอยู่ในเครื่องของคุณเท่านั้น
   - ถ้าจะใช้ Private ต้องใช้บัญชีแบบเสียเงินของ GitHub
3. กด **Add file › Upload files** ลากทุกไฟล์ในโฟลเดอร์นี้ใส่ แล้วกด **Commit changes**
4. ไปที่ **Settings › Pages** ช่อง Branch เลือก `main` และ `/ (root)` แล้วกด **Save**
5. รอ 1–2 นาที จะได้ลิงก์รูปแบบ `https://ชื่อบัญชี.github.io/summit-erp-app/` นี่คือที่อยู่ของแอป

### ทางเลือก ข: Netlify Drop (เร็วที่สุด)
1. เข้า app.netlify.com/drop
2. ลากทั้งโฟลเดอร์นี้ไปวาง จะได้ลิงก์ทันที
3. ถ้าไม่สร้างบัญชี ลิงก์จะหมดอายุ ควรสมัครฟรีเพื่อเก็บลิงก์ไว้ใช้ถาวร

## ขั้นที่ 2: ติดตั้งในแต่ละเครื่อง
| เครื่อง | วิธีติดตั้ง |
| --- | --- |
| คอม (Chrome / Edge) | เปิดลิงก์แอป แล้วกดไอคอน "ติดตั้ง" ที่ท้ายช่องที่อยู่เว็บ หรือเปิดเมนู ⋮ แล้วเลือก "ติดตั้ง SUMMIT School ERP" |
| iPhone / iPad | เปิดลิงก์ด้วย **Safari** แล้วกดปุ่มแชร์ (สี่เหลี่ยมมีลูกศรขึ้น) จากนั้นเลือก **"เพิ่มไปยังหน้าจอโฮม"** |
| Android | เปิดลิงก์ด้วย Chrome แล้วเปิดเมนู ⋮ เลือก **"ติดตั้งแอป"** |

## ขั้นที่ 3: ย้ายข้อมูลจากหน้าเดิมใน claude.ai มาที่แอป
1. หน้าเดิม: ไปที่ ตั้งค่า › สำรอง/กู้คืนข้อมูล แล้วกด **คัดลอกข้อมูลสำรอง**
2. แอปใหม่: ไปที่ ตั้งค่า › สำรอง/กู้คืนข้อมูล แล้ว **วาง** ในช่อง “กู้คืนจากข้อความ” แล้วกดกู้คืน
3. ตรวจดูว่าจำนวนนักเรียนและยอดเงินตรงกับหน้าเดิม

## เมื่อมีเวอร์ชันใหม่
อัปโหลด `index.html` และ `sw.js` ตัวใหม่ทับของเดิม (GitHub: Add file › Upload files) แอปทุกเครื่องจะอัปเดตเองตอนเปิดครั้งถัดไปที่มีอินเทอร์เน็ต ข้อมูลเดิมยังอยู่ครบ
